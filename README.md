TypingTrainer
Пет проект для экспериментирования с современным .NET-стеком

Проект написан на C# с использованием следующих технологий:
ASP.NET Core
ASP.NET Blazor
ASP.NET Identity
Entity Framework Core
 Dependency Injection

Это тренажёр слепой печати с возможностью выбора языка, уровня сложности и хорошей расширяемостью для добавления новых функций.
Основное разделение ответственности
TypingLogic
Чистая бизнес-логика тренажёра, полностью независимая от UI и инфраструктуры.
Основные сущности и интерфейсы:

ITyping — центральный интерфейс, описывающий текущее состояние упражнения
(текст, позиция курсора, статистика, состояние ввода и т.д.)
ICorrectChecker — стратегия проверки введённого символа (разные реализации)
IMistakeProcessor — стратегия обработки неправильно введённого символа (разные реализации)
TypingFactory — фабрика, которая по переданным настройкам создаёт готовый объект ITyping
позволяет легко добавлять новые  комбинации настроек

TypingBlazor.Client
Клиентская часть приложения. В приложение используется рендеринг на стороне клиента.

TypingBlazor (серверная часть)
Логика управления аккаунтом (регистрация, аутентификация через ASP.NET Identity)
Получение и сохранение статистики пользователя
Сервисный слой для связи клиентской части с базой и бизнес-логикой
